# 👔 SMD Styles & Fashions

A modern and responsive Men's Fashion E-Commerce Website built using HTML, CSS and JavaScript.

---

## 🚀 Features

- 🏠 Home Page
- 🛍 Shop Page
- 👕 Product Details
- 🛒 Shopping Cart
- ❤️ Wishlist
- 👀 Quick View
- 💳 Buy Now
- 📦 Checkout
- ✅ Order Success Page
- 🔍 Product Search
- 🎯 Category Filter
- 🔄 Sorting
- 📱 Fully Responsive
- 🔔 Toast Notifications
- ⬆ Back To Top Button
- ⏳ Loading Screen

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage

## 💻 How to Run

1. Clone the repository

```bash
git clone <repository-url>
```

2. Open the project in VS Code

3. Install Live Server extension

4. Run index.html using Live Server
